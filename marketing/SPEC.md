# NBASS 마케팅 운영 콘솔 (Marketing Console) — 개발 명세서

> **버전**: v1.0 (2026-08-29)
> **용도**: 이 문서는 NBASS 본 앱과 분리된 독립 마케팅 앱을 개발할 때의 **단일 진실 공급원(Single Source of Truth)** 입니다.
> AI 코딩 도구나 개발자는 작업 시작 전 반드시 이 문서를 먼저 읽어야 합니다.

---

## 1. 프로젝트 개요

### 1.1 이 앱이란?

NBASS(Neuro-Based Academic Success System) 서비스를 홍보하고 고객을 유입시키기 위한
**오너(대표) 전용 마케팅 운영 콘솔**입니다.

- **사용자**: 오너 1인 (솔로프리너) — 외부 노출 금지, 로그인 보호 필수
- **목적**: 유료 광고 + 무료 바이럴 시딩을 한 곳에서 계획 → 실행 → 성과 측정
- **형태**: NBASS 메인 앱과 **완전히 분리된 독립 웹 앱**
  (NBASS 오너 대시보드의 "SEO/AEO & 100만원 광고" 카드에서 링크로 연결)

### 1.2 왜 독립 앱인가?

1. 마케팅 도구는 오너만 쓰는 운영 도구로, 학생/학부모용 제품과 성격이 다름
2. 광고 계정·API 키·예산 등 민감 정보 분리 보관
3. 시행착오가 많아 잦은 수정이 필요 → 메인 서비스와 배포 사이클 분리
4. 플랫폼 정책 리스크(시딩 등)가 메인 서비스로 전이되지 않도록 격리

---

## 2. NBASS 서비스 개요 (마케팅의 대상)

### 2.1 서비스 정의

NBASS는 뇌과학(뇌파 EEG, HRV 자율신경 분석) 기반의 **학습 집중력 분석 및 처방 서비스**입니다.

- 학생의 뇌파/HRV/심리검사 데이터를 분석하여 학습 밀도, 집중력 패턴, 스트레스 상태를 진단
- 진단 결과를 바탕으로 개인 맞춤 학습 전략·루틴·프로토콜을 AI가 처방
- 학원(제휴 학원)과 개인 학생/학부모 모두를 고객으로 보유
- 핵심 가치: "뇌과학 데이터로 증명하는 우리 아이 집중력과 학습 효율"

### 2.2 핵심 차별점 (광고 카피의 뼈대)

| 차별점 | 마케팅 메시지 예시 |
|---|---|
| 객관적 데이터 (EEG/HRV) | "감이 아니라 데이터로 확인하세요" |
| AI 맞춤 처방 | "우리 아이 뇌에 맞는 공부법" |
| 학습 밀도 정량화 | "책상에 앉아있는 시간과 진짜 공부한 시간은 다릅니다" |
| 전문 장비/랩 기반 | "전문 기관 수준의 분석을 학원에서" |

### 2.3 타겟 고객

| 타겟 | 특성 | 니즈 | 주 접점 채널 |
|---|---|---|---|
| **학부모** (의사결정자) | 초·중·고 자녀, 교육비 지출 의사 결정, 30~50대 | 자녀 성적/집중력 문제의 "원인 진단", 신뢰할 수 있는 근거 | 네이버 검색, 네이버 카페, 지식인, 페이스북 |
| **수험생** (사용자) | 중·고·재수생, 쇼츠/릴스 소비 습관 | 공부법, 집중력 향상, 성적 향상 꿀팁 | 인스타 릴스, 유튜브 쇼츠 |
| **제휴 학원** (B2B) | 학원 대표/운영자 | 차별화 프로그램, 학부모 설득 소재 | (참고용, 본 콘솔 범위 외) |

### 2.4 전환 목표 (Conversion Goals)

1. **1차**: 무료 집중력 분석 상담 신청 (리드 확보)
2. **2차**: 유료 검사/프로그램 구매
3. **3차**: 제휴 학원 문의 (B2B 리드)

## 3. 예산 정책

- **월 예산: 1,000,000원 (100만원)**
- 채널별 배분은 콘솔에서 오너가 직접 조정 가능하며, 기본 배분안:

| 채널 | 기본 배분 | 비율 | 역할 |
|---|---|---|---|
| 네이버 성과형 디스플레이/검색광고 | 400,000원 | 40% | 학부모 타겟, 구매 의도 높은 트래픽 |
| 메타(인스타/페이스북) 릴스 전환광고 | 300,000원 | 30% | 수험생/학부모, 인지도+전환 |
| 구글 디맨드젠 & 유튜브 쇼츠 | 200,000원 | 20% | 공부법/집중력 키워드, 발견형 트래픽 |
| AEO/GEO 바이럴 시딩 운영비 | 100,000원 | 10% | 지식인 답변, 카페 활동 등 무료 채널 운영 보조 |

- 예산 소진률, 채널별 ROAS/CPC/전환율을 주간 단위로 비교하는 것이 콘솔의 핵심 기능

## 4. 핵심 모듈 정의 (4개)

콘솔은 하나의 앱 안에 아래 4개 모듈을 **탭/메뉴**로 통합합니다.
각 모듈은 폴더 단위로 느슨하게 분리하고, 공통 레이어(예산/성과/타겟/콘텐츠)만 공유합니다.

### 모듈 1: AEO/GEO 바이럴 시딩 & Q&A (지식인/카페)

**목적**: AI 답변(ChatGPT, 네이버 AI 요약 등)과 검색 결과에 NBASS가 인용되도록 콘텐츠 자산을 구축

**기능 요구사항**:
- 키워드 뱅크: "집중력 향상", "공부법", "아이 집중력 문제", "학습 밀도" 등 타겟 키워드 관리
- 질문 발굴: 지식인/카페에서 답변할 질문 후보 수집 및 우선순위 관리
- 답변 초안 생성: AI로 NBASS 관점의 전문 답변 초안 작성 (직접 광고가 아닌 정보 제공형 톤)
- 작업 파이프라인: 발굴 → 초안 → 검수 → 게시 → URL/링크 기록 → 성과 추적
- 게시물 대장(ledger): 게시일, 플랫폼, URL, 키워드, 상태 관리
- AEO 체크리스트: 질문형 제목, 구조화된 답변, 출처 표기 등 AI 인용 최적화 가이드

**주의**: 플랫폼 정책(네이버 지식인 자가답변 제한 등)을 준수하는 방식으로 운영 가이드를 문서화할 것

### 모듈 2: 네이버 성과형 디스플레이/검색광고 (학부모 타겟)

**기능 요구사항**:
- 캠페인/광고그룹/키워드 계획 수립 및 기록
- 네이버 검색광고 API 연동(가능 시) 또는 수동 성과 입력
- 지표: 노출, 클릭, CPC, 전환, 전환율, 소진액
- 학부모 타겟 키워드 제안 (예: "아이 집중력", "공부를 안 해요", "학습 집중력 검사")

### 모듈 3: 메타(인스타그램/페이스북) 릴스·숏폼 전환광고 (수험생/학부모)

**기능 요구사항**:
- 릴스 광고 소재 캘린더 (기획 → 촬영 → 편집 → 게시 → 광고 집행)
- 메타 마케팅 API 연동(가능 시) 또는 수동 성과 입력
- 소재별 성과 비교 (후킹 구간, CTA 유형별)
- 타겟 세팅 기록: 연령, 지역, 관심사(공부, 수능, 내신 등)

### 모듈 4: 구글 디맨드젠 & 유튜브 쇼츠 (공부법/집중력 키워드)

**기능 요구사항**:
- 디맨드젠 캠페인 계획 및 성과 기록
- 쇼츠 콘텐츠 파이프라인 (아이디어 → 대본 → 제작 → 게시 → 광고)
- 키워드/주제 뱅크: "공부법", "집중력 키우는 법", "뇌과학 공부" 등
- 구글 애즈 API 연동(가능 시) 또는 수동 성과 입력

## 5. 공통 기능 (전 모듈 공유 레이어)

1. **통합 대시보드**
   - 채널별 예산 소진률, 지출, 전환, ROAS를 한 화면 비교
   - 주간/월간 성과 추이 차트
2. **예산 관리**
   - 월 예산 설정, 채널별 배분 조정, 소진 기록
3. **타겟 관리**
   - 학부모/수험생 페르소나 정의, 채널×타겟 매트릭스
4. **콘텐츠 자산 관리**
   - 카피, 대본, 답변 초안, 이미지/영상 소재 저장소
5. **리포트**
   - 주간 마케팅 리포트 자동 생성 (AI 요약 포함)
6. **보안**
   - 오너 전용 로그인 (환경변수 기반 인증 또는 간단한 비밀번호 게이트)
   - API 키는 `.env`로만 관리, 절대 클라이언트에 노출 금지

## 6. 기술 스택 및 구조 권장안

- 워크스페이스의 `schedule/`, `study/` 서브앱과 동일한 패턴으로 `marketing/` 폴더에 독립 구성
- **프론트**: React + Vite + TypeScript (기존 서브앱과 동일)
- **백엔드**: 경량 서버(`server.ts`) — 광고 API 프록시 및 키 보관 전용
- **데이터**: 초기에는 로컬 저장(JSON/SQLite)으로 시작, 필요 시 Supabase로 확장
- **배포**: NBASS 오너 대시보드에서 딥링크 또는 iframe 임베드로 연결

```
marketing/
├── SPEC.md              ← 이 문서
├── package.json
├── vite.config.ts
├── server.ts            ← 광고 API 프록시, 키 보관
├── index.html
└── src/
    ├── App.tsx
    ├── types.ts
    ├── components/
    │   ├── Dashboard/   ← 통합 대시보드
    │   ├── Budget/      ← 예산 관리
    │   ├── AeoSeeding/  ← 모듈 1
    │   ├── NaverAds/    ← 모듈 2
    │   ├── MetaAds/     ← 모듈 3
    │   ├── GoogleAds/   ← 모듈 4
    │   └── Contents/    ← 콘텐츠 자산
    └── data/            ← 키워드 뱅크, 페르소나 초기 데이터
```

## 7. NBASS 메인 앱과의 연동 지점

| 연동 지점 | 방식 |
|---|---|
| 오너 대시보드 "SEO/AEO & 100만원 광고" 카드 | 콘솔로의 딥링크/iframe 임베드 |
| 성과 요약 (선택) | 콘솔이 주간 요약 JSON을 export → 대시보드 표시 |
| 리드 데이터 (선택) | 광고로 유입된 상담 신청 건을 콘솔에서 추적 (UTM 파라미터 기준) |

## 8. 개발 우선순위 (MVP → 확장)

1. **MVP (1단계)**
   - 오너 로그인 게이트
   - 통합 대시보드 + 예산 관리 (수동 입력 기반)
   - 모듈 1 (AEO/GEO 시딩): 키워드 뱅크 + 질문 발굴 + 답변 초안 생성 + 게시물 대장
2. **2단계**
   - 모듈 2~4 캠페인 계획/성과 수동 기록
   - 주간 리포트 자동 생성
3. **3단계**
   - 네이버/메타/구글 광고 API 연동
   - UTM 기반 리드 추적, NBASS 대시보드 성과 요약 연동

## 9. 용어 정리

- **AEO (Answer Engine Optimization)**: ChatGPT 등 AI 답변 엔진에 콘텐츠가 인용되도록 최적화
- **GEO (Generative Engine Optimization)**: 생성형 AI 검색 결과에 노출되도록 최적화
- **시딩**: 커뮤니티/지식 Q&A에 정보 제공형 콘텐츠를 배포하는 활동
- **ROAS**: 광고수익률 (매출 ÷ 광고비)
- **디맨드젠 (Demand Gen)**: 구글의 발견형 광고 상품 (유튜브, Gmail, Discover 등에 노출)
